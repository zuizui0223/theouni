# Prior-art comparison matrix — 2026-09-04

## Purpose

This matrix converts the novelty firewall into citation-ready comparisons. It is intentionally asymmetric: prior work is credited for every classical substrate or direct motif that has been verified; the dissertation is allowed to foreground only the remainder that survives that comparison.

A row marked **not the same quantifier** does not mean historically novel. It means only that the verified neighbour does not, from the audited source, state the same quantified package. Historical priority remains blocked by `thesis/prior_art_risk_registry.json`.

## Global writing rule

Each chapter Introduction/Discussion should use the following order:

1. name the established substrate and cite it;
2. say what that substrate already solves;
3. state the source-owned question that is narrower/differently typed;
4. give the proved condition or locked decision;
5. state the remaining difference without priority language;
6. state the claim ceiling.

This ordering is deliberately stronger than a generic “to our knowledge” sentence because it makes the nearest neighbour visible before the contribution claim.
