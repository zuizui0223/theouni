# Chapter transition recovery ledger

## Decision

The nine chapter transitions are **question handoffs**, not theorem implications.

The dissertation can still feel cumulative without pretending that one repository proves the next. The rule is:

```text
previous chapter closes one tempting shortcut
    -> a differently typed question remains open
    -> the next source-owned chapter takes that question
```

This is an editorial relation. It does not transfer theorem ownership, evidence, state definitions, or empirical support.

## Recovered handoffs

### 0 → 1: reuse → identification

Chapter 0 poses the reuse problem and uses TU-1 as an exact revision-after-compression example. It does **not** prove the boundary theorem. Chapter 1 supplies the first concrete limit: the observation map can leave latent mechanism directions unidentified even when the endpoint is known.

### 1 → 2: identification → warning

Mechanism identification and warning discrimination are orthogonal estimands. A mechanism can remain unresolved while an observable signal still predicts outcomes; conversely, a signal can identify some process coordinate yet be a poor warning. Chapter 1 therefore opens, but does not answer, the Chapter 2 question.

### 2 → 3: warning failure → measurement choice

Restoring non-events shows that reproducible temporal precedence is insufficient for warning validity. This motivates explicit selection among candidate measurements, but MROD is **not a rescue analysis of EGWE thresholds**. It optimizes current mechanism-information value under its own declared admissible-region contract.

### 3 → 4: measurement choice → state multiplicity

MROD can rank observations only relative to a declared mechanism vocabulary and inferential target. It does not determine one universal ecological state. Chapter 4 therefore asks which target-dependent eco-genetic states must be distinguished in the first place.

### 4 → 5: multiple states → open-future memory

Finite eco-genetic state separation shows that one summary need not represent all scientific responsibilities. CCOC then asks a separate structural question: how exact compression changes when the legal future response grammar is opened. No CCOC lower bound is inferred from the eco-genetic simulations.

### 5 → 6: open grammar → capability

CCOC shows that a narrow physical boundary can hide a large open-future response burden. CREST asks a neighboring but different question: whether a small increment in **admissible management capability** bounds the required-state and monitoring-resolution increment. The CCOC relay is not the proof of the CREST theorem.

### 6 → 7: capability change → structural replacement

CREST changes what actions/responsibilities are admitted on a controlled system. MLTR changes the source-target structure and preserves inherited source semantics. These are different transports. The transition asks whether a law that is adequate under one structure remains valid when the structure itself is replaced.

### 7 → 8: law transport → evidence reliability

A structurally valid/repaired state-law interface can still be poorly identified by its observation architecture. CED therefore addresses a separate bottleneck: whether repeated evidence and failure diversity justify the required target split. Replacement histories are not failure domains.

### 8 → 9: evidence architecture → typed synthesis

CED closes the final simple shortcut—raw replicate count is not an automatic evidence-strength certificate. Chapter 9 then asks whether any of the dissertation's richness proxies deserves a privileged validity status. The answer is a typed synthesis, not a pooled effect or one global scalar theorem.

## Source-precondition firewall

Editorial order must never create missing scientific prerequisites.

- **EGWE:** loss endpoints and event/non-event labels are frozen in its source contracts; Chapter 2 does not derive them from later Chapter 4.
- **MROD:** mechanism vocabulary, evidence roles, admissible-region rule and candidate observation partitions are declared locally.
- **MLTR:** source/target systems, replacement routes and inherited labels are declared locally.
- **CED:** failure domains, availability/reliability assumptions, target and false-resolution contract are declared locally.

## Writing rule

At the end of each chapter, write the transition as a question, not an implication. Avoid:

> “Therefore Chapter N+1 follows.”

Prefer:

> “This result closes X, but leaves Y unresolved. The next chapter asks Y under a different source-owned contract.”
