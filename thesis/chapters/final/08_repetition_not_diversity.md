# 反復は、多様性の代わりにならない

*English working title: Repetition Does Not Substitute for Diversity*

## Problem

同じ手法を繰り返した ⇒ 証拠が強くなった という推論を、なぜこの章では許してはいけないのかを問う。

## Headline result

Repeated observations sharing one failure domain cannot generally substitute for independent failure opportunities; target reporting remains set-valued unless the declared observation and risk contract supports sharper resolution.

## Why the result is nontrivial

replicate 数が増えても shared weather・sensor・observer・laboratory failure を共有するなら、独立な証拠機会と同じ保証にはならない。

## Ecological payoff

調査設計を「何回測ったか」から「どの failure domain を独立に横断したか」へ移せる。

## Claim ceiling

- repetition 一般が無価値とは言わない。
- exact compatible set と risk-limited singleton report を混同しない。
