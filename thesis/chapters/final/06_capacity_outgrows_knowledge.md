# 能力は知識を追い越す

*English working title: Capacity Can Outgrow Knowledge*

## Problem

介入の規模が小さい ⇒ 表現と監視の負担も小さい という推論を禁じるだけでなく、capability gainだけからrequired state / monitoring burdenを上界できるかを問う。

## Headline result

For every `m>=1`, one newly admitted `probe` action adds exactly one world to the greatest robust controlled carrier while refining a retained present slice from one exact state to `2^m` exact states and changing fixed-monitoring debt from `0` to exactly `m` bits. Hence no finite universal upper bound on required present-state resolution can depend only on carrier-size gain. The same evidence can nevertheless continue to license a declared coarse target.

## Why the result is nontrivial

「介入が増えれば情報も必要」ではない。capability consequenceを **+1 viable worldに固定**したまま state/evidence burdenを任意の`m`にでき、しかも同じ`probe` trajectoryがreadoutと新規viabilityを一つのconnected system内で結ぶ。さらにfull-state unlicensedでもtarget reportabilityは残り得る。

## Ecological payoff

小さな新規介入だから既存監視で十分、あるいは逆にfull stateを識別できないから何も報告できない、という両方の近道を禁止できる。

## Claim ceiling

- carrier gainがmonitoring debtを因果的に生む、またはその大きさを決定するとは言わない。
- `m bits`を実地のsample size・金銭コスト・心理的knowledgeへ読み替えない。
- finite deterministic theoremを経験的conservation lawへ拡張しない。
