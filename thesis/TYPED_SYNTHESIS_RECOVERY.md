# Typed synthesis recovery — Chapter 9

## Purpose

Chapter 9 uses the phrase **“妥当性に特権的な方向はない”**. This must not be read as a single global theorem that more information is always worse, or that every notion of richness is ordered on one common scale.

The safe recovery is typed. Chapters 1–8 each reject one monotone shortcut inside its own scientific responsibility.

## Eight typed failures of monotone shortcuts

| Chapter | Richness proxy | Shortcut that fails | Direct recovery |
|---:|---|---|---|
| 1 | observational richness / mechanistic proximity | richer observation ⇒ stronger mechanism identification | `k-1-r` residual identification dimension; unanchored gauge directions remain |
| 2 | reproducible lead-before-loss ordering | more consistent precedence ⇒ better warning | perfect event precedence coexists with firing in every non-event; specificity 0, AUC 0.5 |
| 3 | number/availability of measurable candidates | more things measurable ⇒ more useful evidence; order neutral | truth-peek-free benchmark shows information-guided ordering avoids nuisance measurements and resolves faster |
| 4 | detail in one eco-genetic summary | richer common summary ⇒ adequate state for every target | potential viability, realised occupancy, demographic/genetic quantities and function separate; common marginals can hide transition-relevant alignment |
| 5 | physical/local interface width | narrower boundary ⇒ smaller future-response memory | single-edge relay cut can coexist with `2^m` open distinctions / `m` response bits |
| 6 | size of capability increment | smaller intervention gain ⇒ smaller knowledge burden | one added action can force `1 → 2^m` required states and exactly `m` monitoring bits |
| 7 | exactness/confidence of the source law | valid source law ⇒ valid law after replacement | source-target coherence is required; route disagreement forces explicit history modes |
| 8 | repeated observations / raw replicate count | more repeats ⇒ evidence equivalent to diversified modes | shared failure-domain ceiling remains; independent modes can improve the equal-effort guarantee |

## What Chapter 9 may say

> Across the scientific responsibilities studied here, none of the recorded richness proxies is an automatic certificate of adequacy.

This is stronger than a loose slogan because every row has a source-owned counterexample or theorem. It is weaker than a universal monotonicity theorem because the rows use different carriers, estimands, contracts and order relations.

## What Chapter 9 may not say

Do not claim:

- that “more information” universally reduces adequacy;
- that all eight rows live on one scalar information axis;
- that observation count, state cardinality, memory bits, capability size, structural change and replicate count are interchangeable quantities;
- that the source programmes jointly prove one global partial order over ecological representations;
- that pairwise counterexamples establish a universal law for every possible scientific responsibility.

## Exact substrate versus synthesis

The exact theorem owned by `theouni` remains TU-1: after a state has already been compressed, a revised state is recoverable from the old stored label exactly when the revised quotient factors through the old quotient; otherwise exact auxiliary revision debt is required.

The eight-row matrix supplies a broader **typed synthesis**, not another theorem family. This separation is deliberate:

```text
TU-1
  = exact same-carrier revision theorem

Chapters 1–8
  = source-owned typed failures of automatic reuse / monotone adequacy shortcuts

Chapter 9
  = synthesis: no one of those richness proxies has privileged validity status
```

## Writing rule

When Chapter 9 compares rows, name the type of richness and the type of adequacy every time. Avoid bare sentences of the form “more information is not better.” Prefer statements such as:

- more **observed channels** need not identify more **mechanism coordinates**;
- more **temporal precedence consistency** need not improve **warning discrimination**;
- more **available measurements** need not improve **mechanism resolution per observation**;
- more **replicates in one failure domain** need not improve the same **worst-case guarantee** as diversified modes.
