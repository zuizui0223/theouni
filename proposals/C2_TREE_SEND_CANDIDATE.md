Subject: **Opinion proposal — When more measurement is not more evidence**

Dear Editors,

We would like to propose an Opinion for *Trends in Ecology & Evolution* entitled **“When more measurement is not more evidence.”**

Ecologists and evolutionary biologists can now measure more often, more precisely and with increasingly automated tools, but extra measurements do not always strengthen the evidence for the question at hand. Mature literatures already show several reasons why: greater precision need not resolve mechanisms that remain structurally indistinguishable; information about a system overall need not answer the ecological target or decision that matters; many repeated observations can share the same blind spot; and better downstream processing cannot recreate information that never entered the retained record.

Our proposed Opinion connects these literatures through four properties that measurement must satisfy to become useful evidence for a declared claim: **timely preservation, separation, relevance and failure diversity**. Missing them produces four recurrent failures — too late, same dimension, wrong target and false independence — and each failure requires a different next move. The practical question therefore changes from “how can we measure more?” to **“what distinction must the next measurement create or preserve for the conclusion to change?”**

The framework is a **remedy-matched diagnostic**. When separation is limiting, the next measurement should be one that **separates an unresolved explanation**, not merely the old quantity more precisely. When relevance is limiting, the study needs information that can change its declared prediction, contrast or decision. When shared failure is limiting, another nominal replicate is less valuable than another independent failure opportunity. When preservation is limiting, the distinction must be captured earlier in the observation pipeline, or recalibrated only if it remains in the retained record.

We would develop the argument with two worked examples. In an island *Campanula* design, several mechanisms can remain compatible with the same coarse clinal pattern, so a targeted nectar-guide measurement can be more informative than simply increasing observations of the original pattern. In metabarcoding, deeper sequencing or a better classifier helps only if the focal taxon survived earlier stages such as field sampling, extraction and amplification; when loss occurs upstream, the intervention must also move upstream. Both examples are presented as worked design illustrations rather than new empirical-validation claims.

We think the framework could be useful across field sampling, biodiversity monitoring, sensor networks, experimental ecology, evolutionary inference and adaptive management. The central message is that **additional measurement becomes additional evidence only when it creates or preserves a distinction relevant to the scientific responsibility.**

We have prepared a concise proposal, a completed full Opinion draft for downstream use if invited, and a short reference set positioning the framework relative to structural identifiability, targeted experimental design, value of information, pseudoreplication, imperfect detection, calibration, ecological AI and metabarcoding. We would be grateful to know whether this concept could be suitable for an Opinion in *TREE* before submitting the full manuscript.
